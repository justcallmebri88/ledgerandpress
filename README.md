# Ledger & Press website

This folder is the finished Ledger & Press website, exactly as approved.

## What's inside

- `index.html` is the whole site: the layout, styles and all the interactive parts, including the Experience steps, Try the Press and the inquiry form.
- `images/` holds every photo, cutout and logo the site uses.
- `fonts/` holds Marcellus, Jost and Great Vibes, so the site looks right without depending on Google Fonts.

## See it on your computer

Double-click `index.html` and it opens in your browser. It works offline.

## Working on it in Claude Code

Open Claude Code in this folder and tell it what you want. For example:

- "This is my website. Help me publish it."
- "Connect the inquiry form so submissions come to my email."
- "Change the hero subtitle to ..."

## Before you launch

1. **The inquiry form sends to ledgerandpress@gmail.com** through FormSubmit (formsubmit.co). The first real submission triggers a one-time activation email to that inbox; click the link in it, or later inquiries will not arrive.
2. **The Etsy link points to `https://www.etsy.com/shop/LedgerAndPress`.** Update it in `index.html` if your shop name ends up different.
3. **Hosting.** Any static host works, including Netlify, Vercel, Cloudflare Pages and GitHub Pages. Upload the whole folder, not just `index.html`.
